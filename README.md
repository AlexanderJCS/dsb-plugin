# DSB (Dendritic Spine Beheader)

A Dragonfly 3D World plugin written at the Max Planck Florida Institute for Neuroscience. It provides a fast, semi-automatic method for computing the dendritic spine head radius for hundreds of spines.

It should be used in conjunction with the [DSB proofreader](https://www.github.com/alexanderjcs/dsb-proofreader)
